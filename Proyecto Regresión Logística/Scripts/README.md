# Scripts
Esta carpeta contiene los scripts en R utilizados para el análisis econométrico del proyecto.

## Contenido

- `LENTICOS.R`: Script para el análisis del conjunto de datos de sistemas lénticos.
- `LOTICOS.R`: Script para el análisis del conjunto de datos de sistemas lóticos.

## Funcionalidades

Los scripts incluyen:

- Carga y limpieza de datos.
- Análisis exploratorio.
- Construcción de modelos de regresión.
- Validación de supuestos del modelo.
- Interpretación de resultados.
- Generación de estadísticas y gráficos.

## Requisitos

- R (versión 4.0 o superior)
- Paquetes utilizados en el proyecto (por ejemplo):
  - tidyverse
  - ggplot2
  - dplyr
  - car
  - lmtest

## Ejecución

Abra los archivos `.R` en RStudio y ejecútelos en el orden correspondiente para reproducir el análisis.
